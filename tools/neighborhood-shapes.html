Triplet — Neighborhood Shape Fetcher

Fetches real OpenStreetMap geometry automatically — no manual tracing required for anything OSM already has on file. Districts query Nominatim for the actual administrative/place boundary polygon; streets query Overpass for the actual mapped street path. Every fetched shape is drawn on a small preview map so you can visually confirm it looks right before accepting — that's a stronger check than eyeballing raw coordinates. Anything OSM doesn't have (an informal grouping with no boundary relation) is flagged "needs manual trace" — see the plan doc's §10 for that fallback. Runs at a polite ~1.5s between requests.

Add one more shape later

For any neighborhood/street you want to add after today — no need to edit this file's code. Type it in, fetch it, and paste the result into index.html's NEIGHBORHOODS object yourself. Still a one-time, static addition — this just automates the OSM lookup.
