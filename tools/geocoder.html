Tripline — Bulk Location Geocoder

One-time local tool. Geocodes all Reykjavik/Copenhagen/Malmö/Stockholm places from the trip doc using Nominatim, directly from your browser (not behind any sandbox network restriction). Respects Nominatim's usage policy: 1 request/second, sequential, no caching needed since every query runs once. When done, copy the generated SQL and paste it into the Supabase SQL editor. This file does nothing else — it never talks to Supabase, only to Nominatim.
